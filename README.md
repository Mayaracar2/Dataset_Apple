# 📈 Análise de Séries Temporais — Ações da Apple (1980–2026)

Este projeto foi desenvolvido para a disciplina de **Ciência de Dados com Python (C11)**, do Instituto Nacional de Telecomunicações (Inatel).

## 🎯 Objetivo

Analisar a evolução histórica do preço das ações da Apple, identificando tendências, possíveis padrões sazonais e períodos de valorização e desvalorização, relacionando os resultados à trajetória tecnológica da empresa.

## 📊 Dataset

Os dados foram obtidos no Kaggle:

[Apple Comprehensive Financial Dataset (1980–2026)](https://www.kaggle.com/datasets/adamvakar/apple-comprehensive-financial-dataset-1980-2026)

## 🛠️ Tecnologias utilizadas

- Python
- Pandas e NumPy
- Matplotlib
- Statsmodels
- Scikit-learn

## 📌 Etapas do projeto

- [x] Importação e tratamento dos dados
- [x] Visualização da evolução histórica das ações
- [x] Decomposição da série temporal
- [x] Implementação do modelo Holt-Winters
- [X] Implementação do modelo SARIMA
- [X] Implementação do modelo Prophet
- [X] Comparação dos modelos utilizando MAE, RMSE e MAPE
- [X] Análise dos resultados e conclusões
